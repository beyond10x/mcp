## Prepared specification and measured limits

Prior task-owned scratch inventories the six public value declarations and eighteen
named constructor/HTTP obligations, citing actual source. The ess/17 successor
validates and preserves all nominal constraints. Its full eight authored constructor
selection is refused for three constrained direct-response observations; partial
synthesis emits nine cases with four retained refusals and no execution yet.
ESS0.50 reproduces0.45 on identical inputs; local0.51source retains the same constrained
return and count-invariant boundaries. No upgrade is presumed to fix this.

Actual method return observations must drive real constructors and actual transport
fixtures. Do not invent persistent entities, last-result views, fake outcome values,
or weaken ConnectionId/ToolSnapshot constraints to satisfy synthesis. Select explicit
remaining native checks or upstream support openly; partial coverage stays partial.

Source disagreements remain UNMAPPED: credential value placement versus AGENTS,
unused max_pages, max_frame_bytes limited to HTTP, opaque handle lifetime/registry
custody removal, snapshot persistence, OAuth atomic one-use/refresh/publication fences,
protocol and unsupported capability behavior. Consumer caller assignment and outbound
process ownership are Connectors decisions, not this library's permission to decide.
